朱虹旭个人网站｜静态 HTML 版

一、这个文件夹是什么
这里是一套可直接部署到静态网站服务器或 Nginx 的 HTML/CSS/JS 文件。
请完整上传本文件夹内的全部内容，不要只上传 index.html。

二、本机预览
macOS：双击“启动本地预览.command”，再打开浏览器访问：
http://localhost:8080

也可以在本目录执行：
python3 -m http.server 8080

三、Nginx 部署
1. 把本文件夹内的全部文件上传到网站根目录。
2. 将“nginx.conf.example”中的 server 配置合并到你的 Nginx 配置。
3. 把 your-domain.com 改成你的真实域名。
4. 配置域名解析与 HTTPS 后重新加载 Nginx。

四、注意
直接双击 index.html 可能受到浏览器模块安全限制，请通过本地 HTTP 服务或正式服务器访问。
当前 ChatGPT 在线版本与这套静态 HTML 版本相互独立，可以同时保留。
